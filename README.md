# Rummikub

Python으로 개발하는 온라인 멀티플레이 루미큐브 게임입니다.

## 기술 스택

- **Language:** Python 3.11+
- **GUI:** Tkinter
- **Server:** FastAPI + Python Socket.IO
- **Communication:** Socket.IO
- **Data Format:** JSON

## 프로젝트 구조

```text
rummikub/
├── server/
│   ├── server.py       # Socket.IO 이벤트 및 통신 처리
│   └── state.py        # 보드, 더미, 턴, 플레이어 패 개수 관리
│
├── client/
│   ├── gui.py          # Tkinter 게임 화면
│   ├── network.py      # 서버 연결 및 이벤트 송수신
│   ├── state.py        # 자기 손패 및 보드 상태 관리
│   └── rules.py        # 패 등록 및 보드 규칙 검증
│
└── main.py             # 클라이언트 실행
```

## 역할 분담

| 담당 | 파일 | 역할 |
|---|---|---|
| 서버 | `server/server.py`, `server/state.py` | 플레이어 연결, 턴 관리, 게임 상태 동기화 |
| GUI | `client/gui.py`, `main.py` | 게임 화면 및 사용자 입력 |
| 알고리즘 | `client/rules.py` | 패 조합 및 보드 검증 |
| 클라이언트 로직 | `client/state.py`, `client/network.py` | 손패 관리, 서버 통신 및 상태 갱신 |

## 공통 데이터 규격

패는 고유 ID 없이 `[색상, 숫자]` 형식으로 표현합니다.

```python
["red", 7]
["blue", 12]
["joker", 0]
```

- 색상: `red`, `blue`, `yellow`, `black`
- 숫자: 1~13
- 조커: `["joker", 0]`
- 총 106개 (일반 패 104개 + 조커 2개)

## 데이터 관리

| 데이터 | 서버 | 클라이언트 |
|---|---|---|
| `hand` | X | 자신의 손패 관리 |
| `board` | 확정된 보드 원본 | 보드 복사본 및 편집 |
| `deck` | 원본 관리 | X |
| `turn` | 원본 관리 | 현재 턴 정보 수신 |
| `hand_count` | 모든 플레이어의 패 개수 | 화면 표시 |

## 통신 이벤트

| 클라이언트 → 서버 | 설명 |
|---|---|
| `join` | 게임 참가 |
| `start` | 게임 시작 |
| `play` | 검증된 보드 및 손패 개수 제출 |
| `draw` | 패 뽑기 요청 |
| `end_turn` | 턴 종료 요청 |

| 서버 → 클라이언트 | 설명 |
|---|---|
| `welcome` | 플레이어 ID 전달 |
| `initial_hand` | 시작 패 14개 전달 |
| `draw_result` | 뽑은 패 전달 |
| `state_update` | 보드, 패 개수, 턴 동기화 |
| `error` | 잘못된 요청 |
| `game_over` | 게임 종료 |

## 게임 진행 흐름

1. 플레이어가 서버에 접속합니다.
2. 게임 시작 시 서버가 패를 섞고 각 플레이어에게 14개씩 분배합니다.
3. 각 클라이언트는 자신의 `hand`와 `board`를 관리합니다.
4. 자신의 턴에 `editing_board`를 수정합니다.
5. `rules.py`에서 패 등록 조건과 보드 유효성을 검사합니다.
6. 검증에 성공하면 서버에 `board`와 `hand_count`를 전송합니다.
7. 서버는 현재 턴을 확인하고 보드 및 패 개수를 갱신합니다.
8. 서버가 모든 클라이언트에게 변경된 상태를 전송합니다.
9. 클라이언트는 보드와 패 개수 표시를 동기화합니다.

서버가 제출을 승인한 뒤 클라이언트의 손패 변경을 확정합니다.

## 주요 게임 규칙

- 최대 4명 플레이
- 시작 시 각 플레이어에게 14개 분배
- 최초 등록은 자기 패로 30점 이상
- 같은 숫자·서로 다른 색상 또는 같은 색상·연속 숫자 조합
- 최초 등록 이후 보드 재배치 가능
- 패를 뽑으면 턴 종료
- 손패를 모두 사용하면 승리

## 설치 및 실행

### 1. 라이브러리 설치

```bash
pip install fastapi python-socketio uvicorn
```

### 2. 서버 실행

프로젝트 최상위 폴더에서 실행합니다.

```bash
uvicorn server.server:app --reload
```

서버 주소: `http://127.0.0.1:8000`

### 3. 클라이언트 실행

```bash
python main.py
```

## 개발 원칙

- 서버는 보드, 더미, 턴 및 플레이어별 패 개수를 관리합니다.
- 클라이언트는 자신의 손패와 보드 편집을 담당합니다.
- 게임 규칙 검증은 클라이언트의 `rules.py`에서 수행합니다.
- 서버는 현재 턴인지 확인한 뒤 제출된 상태를 반영합니다.
- 모든 클라이언트는 서버에서 전달받은 보드로 동기화합니다.
- 다른 플레이어의 실제 손패는 공개하지 않습니다.
- 공통 데이터 구조와 이벤트 이름은 팀원 합의 없이 변경하지 않습니다.

> 본 프로젝트는 학습용으로, 클라이언트가 규칙을 정상적으로 검증한다는 전제로 구현합니다.
